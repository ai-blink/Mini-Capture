# Mini Capture

[English](README.md) | [한국어](README.ko.md) | [简体中文](README.zh-CN.md) | 日本語

Mini Capture は、画像のキャプチャ、確認、マークアップ、保存をすばやく行える軽量な Windows 向け画面キャプチャツールです。コンパクトなキャプチャボタンを画面端に表示しておけば、必要なときに領域、ウィンドウ、全画面、タイマーの各モードでキャプチャできます。

## ポータブル版をダウンロード

1. [最新リリース](https://github.com/ai-blink/Mini-Capture/releases/latest)から `MiniCapture-v0.1.6-win-x64-portable.zip` をダウンロードします。
2. ZIP ファイルを任意のフォルダーに展開します。
3. `MiniCapture.exe` を実行します。

インストールや別途 .NET のインストールは必要ありません。初回起動時に Windows SmartScreen の確認画面が表示された場合は、ファイルの提供元を確認してから **詳細情報 → 実行** を選択してください。

> ポータブルフォルダーを移動すると、画像ファイルを開くアプリ候補として登録するパスも変わります。移動先のフォルダーで `MiniCapture.exe` を一度実行すると、現在のパスが登録されます。

## 主な機能

- 常に手前に表示されるコンパクトなキャプチャボタン
- 領域、ウィンドウ、全画面、タイマーの 4 種類のキャプチャ方式
- PNG への自動保存
- PNG、JPG、JPEG を開ける内蔵ビューアと、設定で登録した GIF を元のアニメーションとして再生する機能
- キャプチャフォルダーを閲覧する Windows エクスプローラー風ミニファイルブラウザー
- 詳細、小、中、大の 4 種類のファイル表示
- ウィンドウに合わせる、等倍、拡大・縮小、倍率の直接入力
- ペン、矢印、四角形、楕円、テキスト、モザイクのマークアップ
- マークアップの選択、移動、サイズ変更、削除、元に戻す、やり直す
- 画像コピー、ファイルパスコピー、保存、フォルダーを開く
- `F5` によるファイル一覧の更新と、詳細表示での列の並べ替え
- ピクセル領域の選択、コピー、切り取り、貼り付け、画像端からのトリミング
- ウィンドウキャプチャから除外する実行可能ファイルの一覧管理
- ウィンドウ位置、ファイル表示方式、エクスプローラーパネル幅の保持

## 使い方

### 画像をキャプチャする

画面端の Mini Capture ボタンをクリックし、キャプチャ方式を選択します。

- **領域**: マウスで必要な領域をドラッグします。
- **ウィンドウ**: キャプチャしたいウィンドウの上にマウスを移動して選択します。
- **全画面**: 画面全体をすぐにキャプチャします。
- **タイマー**: 指定した時間が過ぎた後に選択した画面をキャプチャします。

キャプチャファイルは、既定では次のフォルダーに日付ごとに保存されます。

```text
C:\Users\<ユーザー名>\Pictures\MiniCapture\年\月\日
```

### 画像を確認・編集する

キャプチャ結果からビューアを開くか、PNG/JPG/JPEG ファイルまたは設定で登録した GIF を `MiniCapture.exe` で開けます。GIF は最初のフレームで停止せず、元のアニメーションとして再生されます。

ビューア上部のツールバーでは、ファイルの移動、ウィンドウに合わせる、等倍表示、拡大・縮小、回転、マークアップツールを使用できます。

倍率入力欄には `125` または `125%` のように入力できます。対応範囲は 10%～800% です。最下部のステータスバーにあるスライダーでも倍率を調整できます。

### ウィンドウの除外基準を選択する

**設定 → ウィンドウ除外** で実行中のプロセスを選択すると、確認可能な実行ファイルのパスとプロセス名が一緒に保存され、既定の適用基準も自動的にファイルパスになります。

既存のプロセス名だけの項目も、後でパスを確認できればファイルパス基準に更新されます。Windows が実際にパスの照会を禁止する保護プロセスだけが、プロセス名基準で追加されます。

その後はラジオボタンで適用基準だけを切り替えます。切り替えても、2 つの値は保持されます。

### よく使うショートカット

| ショートカット | 動作 |
| --- | --- |
| `Ctrl+S` | 現在の画像を保存 |
| `Ctrl+C` | 選択したピクセル領域をコピー（選択がない場合はマークアップを含む画像をコピー） |
| `Ctrl+X` | 選択したピクセル領域を切り取り |
| `Ctrl+V` | 選択領域の位置に画像を貼り付け |
| `Ctrl+Shift+C` | ファイルパスをコピー |
| `Ctrl+Z` / `Ctrl+Y` | 元に戻す / やり直す |
| `←` / `→` | 前 / 次の画像 |
| `+` / `-` | 拡大 / 縮小 |
| `1` | 等倍 |
| `F` | ウィンドウに合わせる |
| `F5` | 現在のフォルダーを更新 |
| `Delete` | 選択したマークアップを削除 |
| `Space` | 押している間、ハンドツールを使用 |

### Mini Capture を画像拡張子の既定アプリ候補として選ぶ

Mini Capture は起動時に、現在のユーザーアカウントで PNG/JPG/JPEG を開けるアプリ候補として登録されます。ほかの画像拡張子も設定ウィンドウで追加できます。Windows のポリシーにより、既存の既定アプリを強制的に変更することはありません。

1. Mini Capture の **設定 → 拡張子の関連付け** を開きます。
2. ほかの拡張子が必要な場合は、`.bmp` のように入力して **拡張子を登録** を選択します。
3. **Windows の既定のアプリで選択** を選択します。
4. 対象の拡張子の既定アプリとして **Mini Capture Viewer** を選択します。

## システム要件

- Windows 10 または Windows 11
- 64 ビット版 Windows（`win-x64`）
- キャプチャと保存のための、ユーザーの Pictures フォルダーへのアクセス権限

## プライバシーとネットワーク

Mini Capture はキャプチャ画像をユーザーの PC にのみ保存します。V1 には、アカウント、クラウドアップロード、リモート共有、利用状況分析の機能はありません。

## ソースからビルドする

.NET 8 SDK が必要です。

```powershell
dotnet build .\MiniCapture.slnx
dotnet run --project .\src\MiniCapture\MiniCapture.csproj
```

画像ファイルをビューアで直接開くには、ファイルパスを引数として渡します。

```powershell
dotnet run --project .\src\MiniCapture\MiniCapture.csproj -- "C:\path\to\image.png"
```

## ポータブルパッケージを作成する

```powershell
dotnet publish .\src\MiniCapture\MiniCapture.csproj `
  -c Release `
  -r win-x64 `
  --self-contained true `
  -p:PublishSingleFile=true `
  -p:IncludeNativeLibrariesForSelfExtract=true `
  -p:EnableCompressionInSingleFile=true `
  -p:DebugType=None `
  -o .\artifacts\publish\MiniCapture-v0.1.6-win-x64-portable
```

## V1 の範囲

V1 は、安定した画面キャプチャ、自動保存、素早い確認、簡単なマークアップ、キャプチャフォルダーの閲覧に重点を置いています。OCR、クラウドアップロード、スクロールキャプチャ、動画/GIF 録画、高度な画像編集、汎用ファイル管理は含みません。
