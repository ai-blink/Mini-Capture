# Mini Capture Intent

Mini Capture is a lightweight Windows screenshot utility for fast daily capture work. It is intentionally smaller than PicPick or ShareX.

The app should provide:

- A transparent always-on-top capture button.
- Four capture modes: drag region, target window, full screen, and timer delay.
- Automatic PNG saving to a configured folder.
- One-click file open, folder open, and viewer open after capture.
- A fast image viewer with zoom, fit, 100%, and previous/next navigation.
- A Windows Explorer-style mini file browser with a left tree and details/small/medium/large icon views.

The product should not become a full capture suite, image editor, uploader, or general-purpose file manager.
