# Dev Brief

## Purpose

Create a small, reliable Windows capture app that opens fast and removes the friction of unstable or oversized capture tools.

## Current Target

The first build should prove the capture button, capture flow, PNG save path, simple viewer, and Explorer-style browser direction.

## UX Principles

- Always available, never visually loud.
- One click from capture result to file/viewer/folder.
- Viewer and file browser should feel familiar to Windows users.
- The app is capture-first; browsing exists to inspect and manage recent captures.

## Non-Goals

- OCR, upload/cloud sharing, scrolling capture, video/GIF capture.
- Heavy image editing.
- General-purpose file management beyond the capture folder workflow.
