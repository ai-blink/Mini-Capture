# Mini Capture 전체 UI 개편 목업

Date: 2026-07-11

## Finish Line

동일한 V1 기능 범위를 서로 다른 정보 구조로 표현한 자기완결 HTML 시안 3개를 만들고, 각 시안에서 뷰어, 퀵 캡처, 설정 화면을 직접 전환하고 핵심 컨트롤을 조작할 수 있게 한다.

## Acceptance Checks

- 세 HTML이 외부 CSS, JavaScript, CDN 없이 열린다.
- 뷰어에서 파일 선택, 도구 선택, 색상과 두께, 확대/축소가 반응한다.
- 퀵 캡처에서 영역, 창, 전체 화면, 타이머를 선택할 수 있다.
- 설정에서 캡처와 확장자 연결 화면을 전환하고 스위치를 조작할 수 있다.
- 980x580과 일반 데스크톱 크기에서 주요 컨트롤이 겹치지 않는다.

## Scope Limit

- 목업만 추가하며 WPF 구현 파일은 수정하지 않는다.
- OCR, 업로드, 레이어, 범용 파일 관리 기능은 넣지 않는다.
- 기존 캡처 루트, 네 가지 캡처 모드, 마크업 도구, 설정 항목을 기준으로 한다.

## Directions

| 안 | T-Score | 의도 | 구조 |

## Art Direction Notes

### A · Fluent Workbench

- Typography: `Bahnschrift 600-700` 제목, `Segoe UI Variable 400-650` 본문, 본문 행간 1.45, 자간 0.
- Color: `oklch(0.985 0.004 235)`, `oklch(0.23 0.018 235)`, `oklch(0.57 0.13 188)`, `oklch(0.56 0.16 253)`, `oklch(0.82 0.15 88)`.
- Texture: 장식 노이즈 없음. 캔버스에 18px 점 패턴만 사용.
- Grid: 8px 기반. 캔버스 프리뷰, 퀵 버튼, 토스트만 작업 그리드에서 의도적으로 이탈.

### B · Focus Canvas

- Typography: `Bahnschrift 650-750` 제목, `Segoe UI Variable 400-650` 본문, 본문 행간 1.45, 자간 0.
- Color: `oklch(0.13 0.008 45)`, `oklch(0.95 0.008 70)`, `oklch(0.7 0.19 30)`, `oklch(0.78 0.12 165)`, `oklch(0.73 0.11 220)`.
- Texture: 장식 노이즈 없음. 캔버스에 20px 점 패턴만 사용.
- Grid: 6px 기반. 캔버스 내 탐색 버튼, 확대 표시, 하단 필름스트립이 중심 그리드에서 이탈.

### C · Studio Strip

- Typography: `Bahnschrift 700-800` 제목, `Segoe UI Variable 400-700` 본문, 본문 행간 1.4, 자간 0.
- Color: `oklch(0.985 0.004 250)`, `oklch(0.18 0.02 250)`, `oklch(0.88 0.2 125)`, `oklch(0.56 0.22 265)`, `oklch(0.66 0.23 28)`.
- Texture: 장식 노이즈 없음. 캔버스에 28px 선형 그리드만 사용.
- Grid: 6px 기반. 파일 카운터, 비대칭 프리뷰 그림자, 퀵 캡처 스택이 중심 그리드에서 이탈.

## Review Budget And Stop Rule

- 시각 검수와 수정은 최대 두 번 수행한다.
- 화면 겹침, 잘림, 동작 불가만 BLOCKER로 수정한다.
- 취향 차이와 WPF 세부 이식은 선택안 승인 뒤 별도 구현으로 남긴다.

## Verification

- Playwright Chromium에서 세 시안을 `1440x900`, `980x580`로 캡처해 시각 검수했다.
- 파일 선택, 도구 선택, 확대/축소, 캡처 방식, 설정 탭, 스위치를 자동 클릭했다.
- 세 시안 모두 브라우저 콘솔 오류 0건, 본문 가로/세로 오버플로 0건이었다.
- 외부 CSS, JavaScript, CDN 참조가 없고 후행 공백도 없다.
- 두 차례 검수에서 580px 높이 안전성과 B안 좁은 폭 제목 크기를 조정했다.

## A안 범위 조정

- 전체 화면 재배치가 아니라 기존 파일 목록과 탐색 구조를 유지하는 툴바 개선안으로 확정했다.
- 우측 고정 속성 패널을 제거하고 캔버스 폭을 확보했다.
- 펜, 화살표, 네모, 원은 색상과 두께를 보조 툴바에 표시한다.
- 텍스트는 색상과 문구를 보조 툴바에 표시한다.
- 핸드, 선택, 모자이크는 현재 지원되는 추가 속성이 없어 보조 툴바를 숨긴다.
- Playwright로 `1440x900`, `980x580`에서 전환 상태와 파일 목록 유지, 본문 오버플로 0건을 확인했다.
